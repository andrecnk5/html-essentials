# Capítulo 1 - O que é HTML

## Introdução

Bem-vindo ao fascinante mundo do desenvolvimento web! Neste capítulo, vamos explorar os fundamentos do HTML, a linguagem que serve como alicerce para toda a web moderna. Quer você esteja dando seus primeiros passos na criação de websites ou buscando solidificar seus conhecimentos, entender o HTML é essencial para sua jornada como desenvolvedor web.

## 1.1 Definição de HTML

HTML, sigla para HyperText Markup Language (Linguagem de Marcação de Hipertexto), é a linguagem padrão utilizada para criar e estruturar conteúdo na web. Mas o que isso significa exatamente?

- **Hipertexto**: Refere-se à capacidade de criar links entre diferentes páginas ou recursos na web.
- **Marcação**: Indica que o HTML usa tags para "marcar" ou definir diferentes tipos de conteúdo.
- **Linguagem**: É um conjunto de regras e convenções para comunicar instruções ao navegador.

O HTML não é uma linguagem de programação tradicional, mas sim uma linguagem de marcação. Isso significa que ela não executa operações lógicas ou cálculos, mas define a estrutura e o significado do conteúdo em uma página web.

## 1.2 História e Evolução do HTML

O HTML tem uma história rica que remonta ao início da World Wide Web:

1. **1989-1991**: Tim Berners-Lee cria o HTML como parte do projeto World Wide Web no CERN.
2. **1995**: HTML 2.0 é publicado, estabelecendo muitos dos elementos fundamentais que usamos até hoje.
3. **1997-1999**: HTML 3.2 e 4.0 são lançados, introduzindo mais recursos e padronização.
4. **2014**: HTML5 é finalizado, trazendo suporte nativo para multimídia, novos elementos semânticos e APIs poderosas.

Hoje, o HTML continua evoluindo, com atualizações regulares para atender às necessidades de uma web em constante mudança.

## 1.3 Como o HTML Funciona

O HTML funciona através de um sistema de tags que instruem o navegador sobre como exibir o conteúdo. Veja um exemplo simples:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Esta é minha primeira página HTML.</p>
</body>
</html>
```

Neste exemplo:

- `<!DOCTYPE html>` declara que este é um documento HTML5.
- `<html>` é o elemento raiz que envolve todo o conteúdo.
- `<head>` contém metadados sobre o documento.
- `<body>` contém o conteúdo visível da página.
- `<h1>` e `<p>` são tags que definem um cabeçalho e um parágrafo, respectivamente.

## 1.4 A Importância do HTML no Desenvolvimento Web

O HTML é fundamental por várias razões:

1. **Estrutura**: Fornece a estrutura básica para todo o conteúdo web.
2. **Semântica**: Ajuda a dar significado ao conteúdo, crucial para acessibilidade e SEO.
3. **Compatibilidade**: É suportado por todos os navegadores modernos.
4. **Base para outras tecnologias**: Serve como fundação para CSS (estilo) e JavaScript (interatividade).

## 1.5 HTML e Acessibilidade

Uma das características mais importantes do HTML é seu papel na criação de websites acessíveis. Usando tags semânticas apropriadas, os desenvolvedores podem garantir que o conteúdo seja compreensível para tecnologias assistivas, como leitores de tela.

Por exemplo, usar `<nav>` para menus de navegação e `<article>` para conteúdo principal ajuda usuários com deficiências visuais a navegar mais facilmente pelo site.

## 1.6 Ferramentas para Trabalhar com HTML

Para começar a trabalhar com HTML, você precisa apenas de um editor de texto simples e um navegador web. No entanto, existem ferramentas que podem melhorar sua produtividade:

- Editores de código como Visual Studio Code, Sublime Text ou Atom
- Validadores HTML online para verificar seu código
- Navegadores com ferramentas de desenvolvedor integradas (como Chrome DevTools)

## Conclusão

O HTML é a linguagem fundamental da web, fornecendo a estrutura sobre a qual todos os websites são construídos. Ao dominar o HTML, você está dando o primeiro passo crucial em sua jornada como desenvolvedor web. Nos próximos capítulos, exploraremos em detalhes como usar diferentes elementos HTML para criar páginas web ricas e significativas.

Lembre-se: a prática leva à perfeição. Experimente criar suas próprias páginas HTML simples e veja como o navegador as interpreta. Com tempo e experiência, você se tornará proficiente nesta linguagem fundamental.
