# Curso de HTML

Bem-vindo ao curso de HTML! 

Este curso é destinado a iniciantes que desejam aprender os fundamentos da linguagem HTML para criar páginas web. 

HTML (HyperText Markup Language) é a linguagem padrão para construção de páginas web e é uma habilidade essencial para desenvolvedores web.
